# uranium-install

Shell scripts that install and start UraniumOS.

| Script | Purpose |
| --- | --- |
| `uranium-install` | installer for the live medium, menus or an answer file |
| `uranium-desktop` | sets up a desktop (xfce, sway, cinnamon, mate or i3) for a user |
| `uranium-session` | starts a user's desktop from the first console |
| `uranium-chroot` | runs a command in the installed system |
| `genfstab` | writes `/etc/fstab` for a mounted system |
| `uranium-man` | opens the handbook on the live medium |
| `uranium-tip` | prints a tip at login |
| `rod` | bootstrap rod that installs the first packages |

`uranium-mklive` copies them into the system. Handbook: https://uranium-os.github.io
